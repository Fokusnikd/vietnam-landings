# vietnam-landings

Packages site for massage and spa studios in Vietnam. Vietnamese is the default at `/` and English is pre-rendered at `/en`, both generated from `content.json` by `node build.js`. It deploys on Vercel as a static site after that build.

The pages send `noindex` until Remedy Spa consent and a native-speaker check of the Vietnamese copy are done. Prices for a domain or hosting are not shown. Phone numbers, timelines, payment terms, the demo URL, and Aleksandr’s photo stay as visible placeholders in `content.json`.
